## English

This batch adds 40 bilingual entries: 38 included and 2 candidates. It selects repositories from the previously reviewed AI shortlist that showed at least 1,000 added stars in monthly Trending charts captured on 2026-11-17. Weekly-chart entries are outside this batch.

GitHub Trending and its language charts provide discovery leads, not an exhaustive global star-growth ranking. Monthly gains select this batch; the catalog and entry headers show separately fetched total-star snapshots. This selection threshold does not change the catalog's general inclusion criteria.

Repository names and stable GitHub IDs were checked against the existing 209 entries. Classification follows primary use: models, agent frameworks and memory belong to AI tools; coding skills, IDEs, browser development interfaces and review tools belong to development; media generation and processing belong to media; financial research and SEO analysis belong to data; device control belongs to automation; sandbox runtimes belong to operations. A CLI alone does not make a project a terminal tool.

Each entry covers functionality, requirements, limitations and getting started. License evidence pins the reviewed text to a commit and records its SHA-256. Code licensing is assessed separately from weights, datasets, assets and services. Mixed-license entries name the included scope. Activity review checks specific changed files; documentation-only, star-chart refreshes and mechanical dependency updates do not establish substantive maintenance.

This was a documentation and source-change review; upstream projects were not installed or run. Entries without sufficient evidence remain candidates with reasons and follow-up actions. Existing entries and their evaluation dates were preserved.

- `python3 -m unittest discover -s tests -v`：运行现有目录校验回归测试。 / Runs the existing catalog validation regression suite.
- 本批另核对 40 个目标身份、249 个词条唯一性、许可文件哈希、维护变更文件、月榜来源和原有文件未变。 / Batch checks cover the 40 selected identities, uniqueness of 249 entries, license hashes, activity files, monthly sources and preservation of existing files.

每项的具体榜单、仓库、README、许可和维护链接均保存在对应词条的 Review evidence 中。 / Per-entry Review evidence records the specific chart, repository, README, license and maintenance sources.
