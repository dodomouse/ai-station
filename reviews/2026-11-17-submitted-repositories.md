This review covers 57 identified GitHub repositories: **26 added**, **6 already cataloged**, and **25 excluded**. Exclusions were not added as candidates.

来源包括 21 个直接提交的链接，以及 PDF《办公室 Skill 从夯到拉(纯主观)》中可确认的 36 个不同仓库。同仓库中的多个技能合并复核；另有 5 个名称不能唯一定位。Deckary consulting-slides 在文中明确为站外 ZIP 分发，不作为 GitHub 仓库处理。文章的排名、Star 与维护状态只作查找线索。

The PDF was read across all ten pages, including link annotations and embedded comparison images. Its rankings and historical claims are discovery leads, not eligibility evidence. Repeated skills from one repository are reviewed together. Five ambiguous names remain unresolved; Deckary is described as an off-GitHub ZIP distribution.

维护窗口为 2026-08-17 至复核日。检查公开状态、名称与稳定 ID、许可原文及范围、功能实现、实质维护和使用限制。Skill 的实际工作指令可作为功能实现；纯宣传、索引刷新或机械更新不计入。Star 不设门槛。

The maintenance window starts on 2026-08-17. Checks cover repository identity and state, original license text and scope, implementation, substantive activity and usage limits. Functional skill instructions count as implementation; promotional edits and mechanical refreshes do not. There is no star threshold.
