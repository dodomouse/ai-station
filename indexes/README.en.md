## AI tools

- [ai-memory](../tools/ai-memory/README.en.md) — Shared project memory for coding assistants, with searchable notes, session handoffs and optional document import and summaries.
- [dsh-superagent 研究原型](../tools/dsh-superagent-prototype/README.en.md) — Research code for an agent that monitors one GitHub repository and optionally Feishu, then works on authorized tasks.
- [Magpie](../tools/magpie/README.en.md) — A local gateway that routes coding-agent requests across configured model providers and accounts, with optional failover and masking.

## Development

- [AI Website Cloner Template：网站复刻与迁移模板](../tools/ai-website-cloner-template/README.en.md) — A Next.js template and agent workflow for observing existing webpages and rebuilding their layout, assets and interactions as editable code.
- [Archify](../tools/archify/README.en.md) — Turns ideas, plans and repository material into interactive HTML diagrams and explanatory pages with source references.
- [CLI-Anything](../tools/cli-anything/README.en.md) — A framework for building command-line interfaces that drive real application backends, including JSON output and interactive workflows.
- [code-review-graph](../tools/code-review-graph/README.en.md) — Builds an incremental local code graph for dependency queries, impact exploration and review context.
- [Craft Anything](../tools/craft-anything/README.en.md) — An early application-research and rebuilding workspace that combines inspection, agent-assisted implementation and comparison.
- [Graphify](../tools/graphify/README.en.md) — Builds queryable graphs from code and other materials, supporting relationship exploration and visual explanations.
- [Moli：面向 AI 智能体的无头浏览器](../tools/moli/README.en.md) — A Rust headless browser for JavaScript execution, page extraction and browser automation, with optional layout, screenshots and PDF output.
- [Orca（智能体开发工作台）](../tools/orca/README.en.md) — A coding-agent workspace with multiple project views, terminals, change review, remote SSH and mobile companions.
- [REA — Reverse Engineer Anything](../tools/rea/README.en.md) — CLI and MCP tooling for examining binaries, JavaScript, desktop apps and websites with multiple analysis backends.
- [Skills For Real Engineers（Matt Pocock）](../tools/skills/README.en.md) — Composable coding-assistant skills for requirements, architecture, implementation, review and refactoring.
- [Spec Kit](../tools/spec-kit/README.en.md) — A toolkit for specification-driven development, connecting requirements, plans, tasks and implementation through agent workflows.

## Terminal and shell

- [Ghostty](../tools/ghostty/README.en.md) — A terminal emulator with a native interface, GPU rendering, tabs and split panes.

## Data processing

- [AI Berkshire](../tools/ai-berkshire/README.en.md) — Agent skills for company research, financial statements, valuation and tracking investment theses from multiple perspectives.
- [Vibe Research](../tools/vibe-research/README.en.md) — A research workspace for watchlists, holdings, company and sector studies, reports and backtesting across supported markets.

## Automation

- [Agent Autoloop](../tools/agent-autoloop/README.en.md) — A local event and scheduling service that dispatches tasks to installed command-line agents and records their results.
- [Reason Network](../tools/reason-network/README.en.md) — A background network for communication between agent sessions across teammates, devices and projects.

## Operations

- [Clash Verge Rev](../tools/clash-verge-rev/README.en.md) — A graphical proxy client built around Mihomo, with profile management, routing rules, system proxy and TUN controls.

## Productivity

- [best-skills](../tools/best-skills/README.en.md) — A collection of agent workflows for papers, patents, presentations, graphics, code and document processing.
- [GenOffice](../tools/genoffice/README.en.md) — An office workspace with desktop, CLI and MCP interfaces for editing, converting and searching documents.
- [Horizon：AI 信息聚合与双语新闻简报](../tools/horizon/README.en.md) — Collects information from RSS, communities and other configured sources, filters and scores it, and produces bilingual reading reports.
