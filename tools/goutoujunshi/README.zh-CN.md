## 038 狗头军师

仓库：[shengjidaguai-china/goutoujunshi](https://github.com/shengjidaguai-china/goutoujunshi)

### 1. 简介

可分析用户叙述、聊天截图和已导出文本，给出回复草案与行动选项。

### 2. 适用场景

- 恋爱聊天不知道怎么回复。
- 分析关系投入是否失衡。
- 聊天记录里哪些是事实哪些是猜测。

### 3. 主要功能

- 可分析用户叙述、聊天截图和已导出文本，给出回复草案与行动选项。
- 按关系阶段、现实条件、互惠和风险组织分析，不把性格标签当成确定结论。
- 经用户同意可保存本地精简记忆；ChatLab 是可选的已导出聊天数据分析工具。

官方来源入口：[官方 README](https://github.com/shengjidaguai-china/goutoujunshi/blob/main/README.md)。 能力按原卡核对日期理解。

### 4. 使用限制

需要可读取 Skill 的助手及用户有权使用的素材。长期记忆需另行同意，不能从建议推断他人真实意图。本次没有导入私人聊天或安装技能。
