## 026 Awesome DESIGN.md

仓库：[VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)

### 1. 简介

收集知名网站设计语言的 DESIGN.md 文档。向编码智能体提供配色、字体、设计变量和界面规则。

### 2. 适用场景

给 AI 生成页面提供设计参考。比较不同网站的界面风格。为项目编写 DESIGN.md 设计约束。

### 3. 主要功能

| 能力 | 具体作用 | README 核对位置 |
| --- | --- | --- |
| 现成 DESIGN.md 目录 | 集合链接按 AI 平台、开发工具、数据库、生产力、金融等网站类别组织。 | Collection |
| 设计规则和变量参考 | 设计分析涉及配色、排版、布局、视觉模式和设计变量，供 Agent 作为界面约束。 | What is DESIGN.md? / Collection |
| 供智能体读取的纯文本约束 | DESIGN.md 是普通 Markdown，可放进项目作为 AI 生成界面的风格输入。 | What is DESIGN.md? |
| 按品牌寻找设计语言 | Collection 提供 Claude、Linear、Vercel、Stripe 等网站风格入口及简要视觉描述。 | Collection |
| 请求指定网站的设计说明 | README 链接 Request a DESIGN.md 服务，可提交指定网站需求。 | Request a DESIGN.md |

官方来源入口：[官方 README](https://github.com/VoltAgent/awesome-design-md/blob/main/README.md)。 能力按原卡核对日期理解。

### 4. 使用限制

**平台与环境**

- 可阅读 Markdown 的编程或设计智能体
- Google Stitch 或其他能接收设计文本的环境

- 仓库元数据为 MIT，集合目录可作为资料入口。
- 外链设计文档、定制请求和赞助产品不由仓库许可证自动保证免费。
- 实际页面生成所用智能体或模型的费用另计。

- Collection 是第三方整理的设计分析，不应标作对应品牌官方规范。
- 仓库本身不运行页面编辑、生成或发布。
- 本次没有下载外链文档、使用定制服务或生成界面。

**容易找错的需求（不属于本项目能力）**

- 不是用于编辑 Figma 文件或生成完整组件代码的运行平台。
- 不是免费获取模型算力或额度的工具。

### 5. 开始使用

安装与入门文档：[官方 README](https://github.com/VoltAgent/awesome-design-md/blob/main/README.md)。安装、依赖配置及示例以该入口指向的项目文档为准。

**接入方式**

- GitHub README 目录
- DESIGN.md Markdown 文件
- getdesign.md 外部链接；实际界面生成由其他工具完成

可先阅读 README 与目录，按具体主题进入资料。若要使用附带程序或技能，再按其说明准备环境。
