## 001 中国独立开发者项目列表

仓库：[1c7/chinese-independent-developer](https://github.com/1c7/chinese-independent-developer)

### 1. 简介

汇集中国独立开发者的网站、App 和产品。按日期、作者、项目简介与上线状态组织条目。

### 2. 适用场景

寻找现成网站或 App。了解独立开发产品方向。查找开发者及项目入口。

### 3. 主要功能

| 能力 | 具体作用 | README 核对位置 |
| --- | --- | --- |
| 产品目录 | 主版面收录可打开使用的网站和 App，列出产品介绍、入口和开发者。 | 中国独立开发者项目列表 / 备注与入选标准 |
| 按添加日期浏览 | 按日期更新条目，适合从最近收录的产品向前查找。 | 3. 项目列表 |
| 区分项目状态 | 用开发中、已上线、已关闭或缺乏维护三种标记描述项目。 | 2. 项目有 3 种状态 |
| 细分与历史版面 | 另设需要编程或命令行的程序员版面、游戏版面，以及早年收录项目列表。 | 子版面 |

官方来源入口：[官方 README](https://github.com/1c7/chinese-independent-developer/blob/master/README.md)。 能力按原卡核对日期理解。

### 4. 使用限制

**平台与环境**

- 通过浏览器阅读；列表内产品的平台各不相同

- 免费浏览清单；各外部产品是否收费需分别核对。

- 这是资料目录，不是产品运行平台。
- 上线和维护状态来自列表维护者，本轮未逐个核实。
- 目录不能证明产品安全、收入或可持续经营。

**容易找错的需求（不属于本项目能力）**

- 帮我自动做出一个能盈利的产品。
- 给清单里所有产品统一提供免费会员。

### 5. 开始使用

安装与入门文档：[官方 README](https://github.com/1c7/chinese-independent-developer/blob/master/README.md)。安装、依赖配置及示例以该入口指向的项目文档为准。

**接入方式**

- GitHub Markdown 列表及子版面
- README 内网页和作者链接

可先阅读 README 与目录，按具体主题进入资料。若要使用附带程序或技能，再按其说明准备环境。
