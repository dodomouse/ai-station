### 2. 适用场景

- Clawd 博物馆奇妙夜是用什么做的。

### 3. 主要功能

- 当前 README 列出 36 种艺术风格、9 种解说语法和 8 种参数化片段。
- 包含白板、Vox、3Blue1Brown 等解说方式，以及整片口播参考代码。
- 结合程序绘制、动画库、镜头编排和可选生成角色帧，输出艺术短片。

官方来源入口：[官方 README](https://github.com/alchaincyf/huashu-art-motion/blob/main/README.md)。 能力按原卡核对日期理解。
