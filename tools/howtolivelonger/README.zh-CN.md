### 1. 简介

README 列出 64 篇研究摘要，覆盖食物、运动、睡眠和日常习惯。

### 2. 适用场景

- 饮食运动睡眠的论文去哪里找。
- 哪个长寿指南带研究出处。
- 让 AI 按健康研究回答并带来源。

### 3. 主要功能

- README 列出 64 篇研究摘要，覆盖食物、运动、睡眠和日常习惯。
- 提供原始研究链接、在线阅读及下载仓库后离线阅读。
- howtolivelonger 技能读取 data/evidence.json，回答附研究来源。

官方来源入口：[官方 README](https://github.com/geekan/HowToLiveLonger/blob/main/README.md)。 能力按原卡核对日期理解。
