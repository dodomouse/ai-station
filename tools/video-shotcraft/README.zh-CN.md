## 045 产品宣传片制作

仓库：[Vincentwei1021/video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft)

### 1. 简介

面向产品发布和功能演示，采集真实页面素材后用 Remotion 编排影片。

### 2. 适用场景

- 把我的产品网页做成发布宣传片。
- 用真实软件截图做功能演示视频。
- 成片以后还想改镜头和剪映草稿。

### 3. 主要功能

- 面向产品发布和功能演示，采集真实页面素材后用 Remotion 编排影片。
- 当前 README 列出 124 张镜头配方卡、150 个镜头，覆盖界面特写、文字与图形。
- 交付 MP4，可继续在 Motion Workbench 修改；官方另有剪映草稿导出说明。

官方来源入口：[官方 README](https://github.com/Vincentwei1021/video-shotcraft/blob/main/README.md)。 能力按原卡核对日期理解。

### 4. 使用限制

需要 Node/npm、FFmpeg/ffprobe 及浏览器渲染环境。页面采集取决于可访问内容；模型、素材和声音环境需自行准备。剪映兼容性以官方注明版本为准，未在本机验证。

知识卡未提供完整部署费用或付费服务价格；未记录的费用项目需要另行核对。

### 5. 开始使用

安装与入门文档：[官方 README](https://github.com/Vincentwei1021/video-shotcraft/blob/main/README.md)。安装、依赖配置及示例以该入口指向的项目文档为准。
