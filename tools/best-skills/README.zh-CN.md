## 030 best-skills

仓库：[xstongxue/best-skills](https://github.com/xstongxue/best-skills)

### 1. 简介

收集采用 SKILL.md 格式的智能体工作流程。覆盖论文、专利、汇报、自媒体、图表和代码文档。

### 2. 适用场景

按任务寻找可复用 Skill。生成论文或汇报材料。查找绘图与代码文档工作流。

### 3. 主要功能

| 能力 | 具体作用 | README 核对位置 |
| --- | --- | --- |
| 论文与专利写作流程 | 提供论文大纲、章节、参考文献、润色等技能。专利技能覆盖题目、权利要求、说明书和附图等环节。 | 本科&硕士学位论文 / 中文发明专利 |
| 汇报与自媒体内容 | 提供周报、汇报、总结，以及公众号文章、封面、正文插图和风格分析等技能。 | 周报 / 汇报 / 总结 / 介绍 / 自媒体创作 |
| 图表与演示材料 | 提供 Draw.io、Excalidraw 及 PPT 相关工作流，覆盖技术图、数据结构、考试示意和答辩演示。 | 图表绘制 / 本科&硕士学位论文 |
| 工程流程与前端设计 | 包含开发流程五步法与前端界面设计相关技能，供智能体按规则执行工程任务。 | 开发流程五步法 / 前端界面设计 |
| 项目文档与简历 | 根据项目材料生成架构或深度文档、项目梳理和简历项目描述。 | 项目文档与简历 / 项目深度文档 |
| Office 文件处理 | 读取、提取、创建、编辑及转换 Word、Excel、PowerPoint。具体技能调用 pandoc、脚本库等工具，部分路径可用 Windows COM 兜底。 | Office 文档处理 |
| PDF 处理 | 涵盖文字表格提取、合并拆分、页面旋转、水印、表单、加解密和扫描件 OCR。 | PDF 处理 |

官方来源入口：[官方 README](https://github.com/xstongxue/best-skills/blob/main/README.md)。 能力按原卡核对日期理解。

### 4. 使用限制

**平台与环境**

- README 提及 Cursor、Claude Code、Codex、OpenClaw 等助手
- 操作系统和依赖因技能不同；Windows COM 仅是部分 Office 兜底路径
- 项目本身没有单独的通用桌面应用

- GitHub 元数据标示 Apache-2.0。具体依赖工具、编程助手、生图或搜索模型可独立收费；不因技能文件开源就认定生成服务免费。涉及第三方材料时另查原来源许可。

- “高质量”等名称是作者定位，功能效果未在本轮实测。
- 每个技能有独立流程、依赖与输入要求，不等于安装一次就能完成所有任务。
- 论文引用、专利文本、工作材料和生成图表仍需事实与格式核对。
- 文稿中关于去 AI 化的表述不代表可验证的检测规避承诺。

**容易找错的需求（不属于本项目能力）**

- 不匹配“不用助手或工具，直接运行这个仓库就能打开完整办公软件”的需求。
- 不能保证论文通过审查、专利获授权或规避 AI 检测。

### 5. 开始使用

安装与入门文档：[官方 README](https://github.com/xstongxue/best-skills/blob/main/README.md)。安装、依赖配置及示例以该入口指向的项目文档为准。

**接入方式**

- SKILL.md 与支持 Agent Skills 的智能体
- 各技能引用的命令行工具或脚本库
- 部分 Office 路径使用 Windows COM
