## 中文

把真实地理与高程数据转换成方块游戏世界。

### 用途与功能

- 生成城市或自然地区的可游览世界

读取OpenStreetMap和高程数据生成地形、道路与建筑；支持的输出包括 Minecraft Java/Bedrock、Luanti 和 Hytale。

### 环境与限制

桌面支持Windows、macOS和Linux；目标游戏及版本需核对。生成质量取决于地理数据，大区域需要更多时间和资源。游戏、地图数据和托管MapSmith服务各有条件，不能从代码许可推及全部。

### 开始使用

从正式发行安装，先选择较小地区和目标游戏格式，再导入生成的世界。 参阅[官方 README](https://github.com/louis-e/arnis/blob/main/README.md)。

## English

Converts geographic and elevation data into block-game worlds.

### Uses and features

- Generate explorable worlds from cities or landscapes

Uses OpenStreetMap and elevation data to generate terrain, roads and buildings, with output paths for Minecraft Java/Bedrock, Luanti and Hytale.

### Requirements and limits

Desktop support covers Windows, macOS and Linux; verify the target game and version. Results depend on geographic data and larger areas need more resources. Games, map data and hosted MapSmith have separate terms beyond the code license.

### Getting started

Install a formal release, choose a small area and target format, then import the generated world. See the [official README](https://github.com/louis-e/arnis/blob/main/README.md).

### Review and provenance

Implements geographic-data processing and multiple world exporters with installable releases. Recent maintenance: [v3.4.0](https://github.com/louis-e/arnis/releases/tag/v3.4.0) (2026-10-31T02:03:04Z). The formal release improves generation of buildings, trees, traffic and world styles.
