# 开源工具字典设计

ai-station 面向中文和英文读者，收录 GitHub 上有明确用途的开源工具。共享元数据用于分类、筛选和资格计算；两篇独立 Markdown 正文用于介绍工具。

当前已实现仓库初始化、双语草稿创建、结构校验、资格计算、本地搜索和目录生成。真实词条尚未收录。自动采集、定时同步与网页搜索属于后续工作。

## 双语内容结构

每个工具使用稳定 ID，目录为 `tools/<id>/`。`tool.json` 保存共用字段；`README.zh-CN.md` 和 `README.en.md` 分别保存正文。两种语言共用一个 GitHub 快照，避免 Star 和维护时间出现差异。

名称保留产品官方写法。摘要、别名和场景使用 `zh-CN` 与 `en` 两个键。正文说明用途、功能、限制、入门方法和替代选择。双语复核要求表达相同的事实和确定程度，不要求逐句翻译。

结构化字段采用 JSON，正文采用 Markdown。当前脚本只依赖 Python 标准库。字段和行为以[中文数据格式](data-format.md)及[English format reference](data-format.en.md)为准。

## 收录范围

第一版面向通用工具，AI 是其中一个分类。优先收录 CLI、桌面应用、浏览器扩展和可部署服务。纯教程、链接合集、课程、示例代码和宣传页面不进入默认目录。

一个工具对应一个主仓库。镜像、独立文档仓库和不同语言的介绍不重复建档。工具改名或仓库转移时保留稳定 ID，并核对 GitHub 仓库身份。

## 收录规则

默认目录要求至少 1000 个 Star、近 3 个日历月有有效维护活动。仓库必须公开、未归档、未禁用。许可证和两种语言的内容需要人工复核。快照有效期为 7 天。

活动窗口按评估时刻倒推日历月。目标月份没有对应日期时取月末，起止时刻均包含。例如，`2026-11-15T00:00:00Z` 对应的窗口起点是 `2026-08-15T00:00:00Z`。

有效活动包括功能或缺陷修复、此类变更的已合并 PR，以及正式发行版。纯文档修改、镜像同步和机器人机械更新不单独作为依据。人工确认后记录活动来源、时间、判断理由和复核时间。

GitHub 的 `pushed` 搜索可以命中任意分支的近期提交，只适合候选发现。程序不把最近推送时间直接当作有效维护证据。[GitHub 仓库搜索说明](https://docs.github.com/en/search-github/searching-on-github/searching-for-repositories)

GitHub 许可证识别有覆盖范围限制。未知值需要人工核对；不能仅因源码公开就认为满足开源条件。[GitHub 许可证接口](https://docs.github.com/en/rest/licenses/licenses)、[OSI 许可证清单](https://opensource.org/licenses)

## 查询与资格

本地查询检索中英文内容，支持名称、别名、摘要、场景、标签和正文。分类与平台可组合筛选。`--lang` 控制结果语言，不限制检索语言。别名由编辑者维护，当前没有自动翻译或语义检索。

默认仅展示 `eligible` 词条。`--all` 可查看草稿和其他资格状态，并保留原因。快照缺失或过期进入 `unknown`；已知硬条件不符进入 `ineligible`；内容或活动证据待复核进入 `needs_review`。

每次本地查询重新计算资格。Markdown 目录是构建时快照，显示评估时间。`build` 同时生成中英文目录和 JSON 导出数据，输入错误不会覆盖现有输出。

## 后续自动化

人工录入先验证词条质量，建议从 5 个工具开始。字段稳定后扩至 30 至 50 个，再接入每日元数据更新和每周候选发现。已有词条需单独刷新，避免只通过近期推送搜索发现工具。

采集阶段可用以下查询初筛。日期应按运行时的窗口更新：

```text
stars:>=1000 pushed:>=2026-08-15 archived:false is:public mirror:false
```

GitHub REST Search 每次搜索最多提供 1000 条结果。较大的查询需要拆分，出现 `incomplete_results=true` 时应记录缺口。按主题搜索也不能保证发现所有符合条件的工具。[GitHub Search API](https://docs.github.com/en/rest/search/search)

后续同步任务需要处理限流、失败重试、许可证变化和仓库转移。失败时保留上次成功快照，超过有效期后退出默认结果。凭据不写入词条、快照或仓库。

网页可复用同一份数据，增加组合筛选和可分享查询链接。首版不需要数据库、账号系统或向量检索。
