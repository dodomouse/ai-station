在浏览器中运行的 Three.js 卡丁车游戏和程序化内容示例。

### 主要功能

- 支持键盘或手柄、AI 对手、漂移和道具。
- 几何、纹理与声音由代码生成，无需构建步骤。

## English

A Three.js browser kart racer and example of procedural game content.

### Features

- Supports keyboard or gamepad input, AI opponents, drifting and items.
- Generates geometry, textures and sounds in code without a build step.

### Requirements and limits

- Requires a desktop browser with WebGL2 and can run from a static server.
- Only the initial functional release is visible, so sustained maintenance and cross-device behavior remain unproven.
