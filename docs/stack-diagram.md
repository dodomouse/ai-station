## 中文

把技术栈描述转换为带服务图标和连线的架构图。支持 SVG、HTML、PNG 和明暗主题，适合项目说明与设计文档。

**环境与限制：** 需要支持技能的编码助手、Python 3.9+；获取图标需要网络，PNG 导出另需 Playwright 与 Chromium。图标和品牌标识仍受各自条款约束。

## English

Turns stack descriptions into architecture diagrams with service icons and connections, exporting SVG, HTML and PNG in light or dark themes for project documentation.

**Requirements and limitations:** Requires a skill-capable coding assistant and Python 3.9+. Icon retrieval uses the network; PNG export also requires Playwright and Chromium. Brand assets retain their own terms.

**Getting started:** Follow the [official documentation](https://raw.githubusercontent.com/caru-ini/stack-diagram/main/README.md) for setup, then check [releases](https://github.com/caru-ini/stack-diagram/releases). This review examined documentation, license text and maintenance evidence; the software was not installed or run.

**Recent maintenance:** [v0.6.0 adds Kubernetes community icons.](https://github.com/caru-ini/stack-diagram/releases/tag/v0.6.0) (2026-11-13)
