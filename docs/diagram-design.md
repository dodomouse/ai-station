## English

An agent skill for producing standalone HTML and SVG diagrams of structures, processes and comparisons.

### Features

- Provides diagram types, visual themes and brand configuration.
- Imports common diagram formats and checks layout and geometry constraints.

### Requirements and limits

- Requires a skill or plugin-capable agent
- some validation and export workflows need Python or browser tools.
- Automatic checks do not replace review of labels, data and relationships.

### Getting started

Choose the platform or integration in the [official documentation](https://github.com/cathrynlavery/diagram-design/blob/main/README.md), review its dependencies and permissions, and follow its quickstart. Check [release records](https://github.com/cathrynlavery/diagram-design/releases) for versions.
