## 中文

面向文本分类、选项判断、评分和路由的非自回归决策引擎，输出结构化结果与置信信息。

**环境与限制：** 需要 Python 3.10+，可在 CPU 或兼容 GPU 上运行并下载模型。附加能力可按需安装，包括服务和 MCP。它侧重决策任务，不是通用长文本生成聊天模型。宣传中的速度仍需在自己的环境测量。

## English

A non-autoregressive decision engine for classification, choice selection, scoring and routing, producing structured outputs and confidence information.

**Requirements and limitations:** Requires Python 3.10+ and model downloads, with CPU or supported GPU execution and optional serving/MCP extras. It targets decisions rather than general long-form chat generation; benchmark performance in your own environment.

**Getting started:** Follow the [official documentation](https://raw.githubusercontent.com/NandhaKishorM/laya/main/README.md) for setup, then check [releases](https://github.com/NandhaKishorM/laya/releases).
