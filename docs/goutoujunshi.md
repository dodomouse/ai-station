#### 2. 适用场景

- 恋爱聊天不知道怎么回复。
- 分析关系投入是否失衡。
- 聊天记录里哪些是事实哪些是猜测。

- 可分析用户叙述、聊天截图和已导出文本，给出回复草案与行动选项。
