## 中文

用记忆卡片与间隔重复安排复习。

### 用途与功能

- 长期学习词汇、知识点与专业术语

支持牌组、复习评分、多媒体卡片、模板和插件；可选AnkiWeb同步。详见[官方网站](https://apps.ankiweb.net/)。

### 环境与限制

本词条是桌面代码。当前下载支持Windows10+x64/Windows11 ARM、macOS13+、较新Linux；移动应用属于不同项目与许可。共享卡片和插件可能携带第三方内容，应及时更新并核对来源。

### 开始使用

从官方网站选择平台安装，先创建小牌组并持续复习，再考虑同步和扩展。 参阅[官方 README](https://github.com/ankitects/anki/blob/main/README.md)。

## English

Schedules flashcard reviews with spaced repetition.

### Uses and features

- Study vocabulary, concepts and technical terminology over time

Supports decks, recall ratings, media cards, templates and add-ons, with optional AnkiWeb synchronization. See the [official site](https://apps.ankiweb.net/).

### Requirements and limits

This entry covers desktop code. Current downloads target Windows 10+ x64/Windows 11 ARM, macOS 13+ and recent Linux. Mobile apps are separate projects with their own terms. Shared decks and add-ons may contain third-party content; keep software current and review sources.

### Getting started

Install the platform package from the official site, create a small deck and review it regularly before adding sync or extensions. See the [official README](https://github.com/ankitects/anki/blob/main/README.md).
