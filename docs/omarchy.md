## 中文

为开发与日常使用预配置桌面、终端、快捷键和工具的Linux发行版。

### 用途与功能

- 搭建统一的Linux工作环境

提供平铺与传统桌面模式、主题、CLI、开发工具及完整配置手册。

### 环境与限制

通过ISO安装；整盘安装会清除目标盘，空闲空间安装也需要正确分区。硬件与启动设置必须按手册核对，默认全盘加密。仓库MIT许可不替代所含软件各自许可，商业应用服务另计。

### 开始使用

先阅读手册与硬件支持，备份后选择测试机器或合适的虚拟环境评估。 参阅[官方 README](https://github.com/omacom/omarchy/blob/quattro/README.md)。

## English

A Linux distribution preconfiguring desktop, terminal, shortcuts and tools for development and daily use.

### Uses and features

- Set up a consistent Linux working environment

Provides tiling and traditional desktop modes, themes, a CLI, development tools and a configuration manual.

### Requirements and limits

Installs through an ISO. Full-disk installation erases the target, and free-space installation still needs correct partitioning. Check hardware and boot settings in the manual; disk encryption is enabled by default. The repository's MIT license does not replace bundled software licenses or commercial-service terms.

### Getting started

Read the manual and hardware guidance, make backups and evaluate on a test machine or appropriate virtual environment. See the [official README](https://github.com/omacom/omarchy/blob/quattro/README.md).
