## 中文

为 Agent 提供网页与社交平台的搜索、阅读和内容获取能力，整合视频、论坛及多个中文平台渠道。

**环境与限制：** 需要 uv、命令行 Agent；部分渠道需要 Chromium、用户登录或可用代理。应使用官方安装说明，PyPI 同名包不是本项目。会话导入涉及本机浏览器登录数据，应只接入自己的授权账号；模型服务另配。

**近期维护：** [v1.6.1 修复渠道空结果、端口与会话复制状态反馈。](https://github.com/Panniantong/Agent-Reach/releases/tag/v1.6.1)（2026-11-01）

## English

Gives agents search and reading tools across websites, video platforms, forums and several Chinese services.

**Requirements and limitations:** Requires uv and a command-line agent; some channels need Chromium, authentication or network access. Follow the repository's installer because the identically named PyPI package is unrelated. Browser-session import uses local login data and should be limited to authorized accounts; configure models separately.

**Getting started:** Follow the [official documentation](https://raw.githubusercontent.com/Panniantong/Agent-Reach/main/README.md) for setup, then check [releases](https://github.com/Panniantong/Agent-Reach/releases). This review examined documentation, license text and maintenance evidence; the software was not installed or run.

**Recent maintenance:** [v1.6.1 fixes empty channel results, port handling and session-copy status reporting.](https://github.com/Panniantong/Agent-Reach/releases/tag/v1.6.1) (2026-11-01)
