## 中文

通过对话配置团队智能体，连接应用，并按计划或事件执行任务。

给 AI 提供应用工具、浏览器、共享文件和权限控制，完成团队运营与文档任务。

### 主要功能

- 通过对话创建智能体并接收改进反馈。
- 在网页、Slack、Telegram 或 WhatsApp 中使用智能体。
- 为工具设置读写权限和人工审批。

### 环境要求

- 选择 Agenta Cloud 或按自托管指南部署。
- 准备托管模型访问方式，或配置 Ollama 自托管模型。

### 使用限制

- Agenta 面向团队的自主任务，不是固定步骤的可视化流程编辑器。
- 连接聊天应用或业务系统时，需要配置各系统权限。

### 开始使用

1. 阅读[官方入门说明](https://github.com/Agenta-AI/agenta/blob/main/README.md#get-started)。
2. 按[自托管指南](https://agenta.ai/docs/self-host/quick-start)部署，或选择 Cloud。
3. 创建一个智能体，配置工具权限并测试任务。

## English

Builds shared team agents through conversation, with connected apps and scheduled or event-triggered runs.

Gives agents app tools, a browser, shared files and permissions for team operations and document work.

### Features

- Create agents through conversation and refine them with feedback.
- Use agents in the web app, Slack, Telegram or WhatsApp.
- Set read/write permissions and human approvals for tools.

### Requirements

- Choose Agenta Cloud or follow the self-hosting guide.
- Provide access to a hosted model or configure a self-hosted model through Ollama.

### Limitations

- Agenta targets autonomous team tasks rather than a visual editor for fixed workflow steps.
- Chat and business-system integrations require permissions in those systems.

### Getting started

1. Read the [getting-started instructions](https://github.com/Agenta-AI/agenta/blob/main/README.md#get-started).
2. Follow the [self-hosting guide](https://agenta.ai/docs/self-host/quick-start), or choose Cloud.
3. Create an agent, configure tool permissions and test a task.
