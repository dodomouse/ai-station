## English

Adds knitted-style borders to macOS windows, with per-app colors, exclusions and active-window distinction.

**Requirements and limitations:** Requires macOS 13+ and accessibility permission. Testing is primarily on Apple Silicon; the application uses private APIs and is not notarized, so OS updates may affect compatibility.

**Getting started:** Follow the [official documentation](https://raw.githubusercontent.com/saragordic/window-sweaters/main/README.md) for setup, then check [releases](https://github.com/saragordic/window-sweaters/releases). This review examined documentation, license text and maintenance evidence; the software was not installed or run.

**Recent maintenance:** [v1.5.0 adds per-app switches and color settings.](https://github.com/saragordic/window-sweaters/releases/tag/v1.5.0) (2026-09-18)
