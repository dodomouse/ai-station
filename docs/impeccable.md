## 中文

为编码智能体提供前端设计、审查和调整命令。

### 用途与功能

- 改进网页视觉与交互
- 检查一致性与常见设计问题

提供设计命令，包括 init、polish、critique 和 audit。配套安装器和引擎支持多种编码工具。

### 环境与限制

需要兼容的编码工具。npx 安装路径需 Node.js，引擎可能首次下载。Loop 和账户计划相关能力应单独核对；不能把 Apache 许可推及所有托管服务。输出质量需实际页面验证。

### 开始使用

在项目根目录按 README 安装，重载编码工具，然后调用 init。 参阅[官方 README](https://github.com/pbakaus/impeccable/blob/main/README.md)。

### 收录与来源

提供多工具安装路径和可执行运行组件，设计调整有明确命令入口。 最近维护：[cli-v4.9.2](https://github.com/pbakaus/impeccable/releases/tag/cli-v4.9.2)（2026-11-16T00:40:46Z）。正式版为 Loop 安装与更新加入固定摘要校验，并改进工具规则接入。

## English

Provides frontend design, review and refinement commands for coding agents.

### Uses and features

- Refine website visuals and interaction
- Check consistency and common design problems

Organizes design work through init, polish, critique and audit, with an installer and engine for multiple coding tools.

### Requirements and limits

Requires a compatible coding tool. The npx path needs Node.js and may download the engine on first use. Check Loop and account-plan features separately; Apache licensing does not cover every hosted service. Validate output on real pages.

### Getting started

Install from the project root as documented, reload the coding tool, then invoke init. See the [official README](https://github.com/pbakaus/impeccable/blob/main/README.md).
