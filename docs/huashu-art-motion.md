## English

An agent-oriented toolkit of art-motion styles, explanatory patterns and reusable animation clips.

### Use cases

- Create visual explainers
- Develop stylized motion sequences

### Requirements and limits

Rendering depends on uv, FFmpeg and Playwright Chromium. Character work needs suitable assets or generation tools. The current README reserves the author's character artwork and lists separate font and stroke-data licenses. Main code is MIT; that does not grant rights to every example asset or supply model credits.
