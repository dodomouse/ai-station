## 中文

结合网页翻译、字幕翻译和词汇复习的浏览器语言学习扩展。

### 主要功能

- 翻译选中文本、网页与支持站点的字幕。
- 保存词汇并按 FSRS 计划复习，也可自定义文本处理动作。

### 环境与限制

- 支持 Chrome、Edge 与 Firefox，AI 功能需要配置兼容服务。
- 采用 GPL-3.0 与商业许可双轨，公开代码按 GPL 使用，网站变化可能影响字幕支持。

### 开始使用

从[官方说明](https://github.com/mengxi-ream/read-frog/blob/main/README.md)选择对应平台或集成方式，核对依赖与权限后按入门步骤操作。[发行记录](https://github.com/mengxi-ream/read-frog/releases)可用于确认版本。

## English

A browser language-learning extension combining page translation, subtitle translation and vocabulary review.

### Features

- Translates selected text, pages and subtitles on supported sites.
- Saves vocabulary for FSRS review and supports custom text actions.

### Requirements and limits

- Supports Chrome, Edge and Firefox
- AI features need a compatible provider.
- Public code is available under GPL-3.0 alongside commercial licensing, and site changes can affect subtitle support.

### Getting started

Choose the platform or integration in the [official documentation](https://github.com/mengxi-ream/read-frog/blob/main/README.md), review its dependencies and permissions, and follow its quickstart. Check [release records](https://github.com/mengxi-ream/read-frog/releases) for versions.
