## English

A desktop workspace that represents working agents as a pixel-art space station.

### Features

- Assigns workspaces, models, memory and capabilities to agents.
- Uses rooms and hallways to represent team boundaries and task handoffs.

### Requirements and limits

- Public desktop releases support Windows and macOS
- Linux packages are internal build artifacts.
- Model calls incur real costs, and early releases have platform differences.

### Getting started

Choose the platform or integration in the [official documentation](https://github.com/androoAGI/starnet/blob/feat/harness-backend/README.md), review its dependencies and permissions, and follow its quickstart. Check [release records](https://github.com/androoAGI/starnet/releases) for versions.
