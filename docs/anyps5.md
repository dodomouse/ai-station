## 中文

研究把控制台可执行文件重链接到桌面平台的兼容性工具。

### 主要功能

- 提供可执行文件重链接、系统库替代实现和着色器转换。
- 公开按游戏和接口统计的兼容性记录。

### 环境与限制

- 主要目标为 Linux 与 Windows，macOS 只支持重链接部分。
- 项目处于早期阶段，不能据此保证游戏可运行，用户需自行提供有权使用的文件。

## English

A compatibility project for relinking console executables to desktop platforms.

### Features

- Provides executable relinking, system-library implementations and shader conversion.
- Publishes compatibility records by game and interface.

### Requirements and limits

- Primarily targets Linux and Windows
- macOS supports the relinker only.
- The project is early-stage and does not guarantee game compatibility
- users must provide files they are entitled to use.

### Getting started

Choose the platform or integration in the [official documentation](https://github.com/boykopovar/AnyPS5/blob/main/README.md), review its dependencies and permissions, and follow its quickstart. Check [release records](https://github.com/boykopovar/AnyPS5/releases) for versions.
