## 中文

从技术资料整理专利交底草稿，并辅助检索、阅读和案卷整理。

### 主要功能

- 组织交底、申请文件、附图与权利要求对照流程。
- 提供 Word 数学公式导出、资料转换和知识库整理脚本。

### 环境与限制

- 脚本使用 Python 3.9+，部分检索与绘图依赖 Playwright 和外部站点。
- 输出是辅助草稿，新颖性、权利范围和申报内容需要专业人员复核。

### 开始使用

从[官方说明](https://github.com/handsomestWei/patent-disclosure-skill/blob/main/README.md)选择对应平台或集成方式，核对依赖与权限后按入门步骤操作。[发行记录](https://github.com/handsomestWei/patent-disclosure-skill/releases)可用于确认版本。

## English

Helps turn technical material into patent-disclosure drafts and assists with search, reading and case organization.

### Features

- Organizes disclosure, application, drawing and claim-comparison workflows.
- Provides Word math export, document-conversion and knowledge-organization scripts.

### Requirements and limits

- Scripts use Python 3.9+
- some searches and diagrams need Playwright and external sites.
- Outputs are working drafts
- novelty, claim scope and filing content require professional review.
