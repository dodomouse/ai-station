## 中文

为编码智能体提供网页设计流程、素材工具和浏览器检查脚本。

### 用途与功能

- 制作企业介绍或产品网页
- 检查响应式布局、素材与文案

提供调色板、版式、照片、图标工具和页面模板。在真实浏览器中检查布局、性能、无障碍和交付条件。

### 环境与限制

脚本需 Node.js 22+ 和 Chrome、Edge 或 Chromium；部分媒体处理可选 FFmpeg。网页生成仍依赖编码智能体。照片、字体和图标各有许可；额外下载需要网络。设计质量与宣传中的对比结果未实测。

### 开始使用

按 README 安装 design-taste-frontend 技能，再让智能体生成页面并运行项目自带检查。 参阅[官方 README](https://github.com/Leonxlnx/taste-skill/blob/main/README.md)。

## English

Provides website design workflows, asset tools and browser checks for coding agents.

### Uses and features

- Build company or product websites
- Check responsive layouts, assets and copy

Includes palette and layout selection, photo and icon tools, page templates, and browser checks for layout, performance, accessibility and completion.

### Requirements and limits

Scripts require Node.js 22+ and Chrome, Edge or Chromium; some media work optionally uses FFmpeg. Page generation still needs a coding agent. Photos, fonts and icons have separate terms, and additional downloads need network access. Design quality and advertised comparisons were not tested.

### Getting started

Install the design-taste-frontend skill from the README, then ask the agent to build a page and run its checks. See the [official README](https://github.com/Leonxlnx/taste-skill/blob/main/README.md).

### Review and provenance
