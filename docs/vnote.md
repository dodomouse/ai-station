## 中文

在本地管理笔记，并编辑Markdown、Typst、文本和思维导图。

### 用途与功能

- 整理技术笔记与多格式文档

提供Markdown预览、Typst实时PDF预览、源码文本编辑、原生思维导图和PDF阅读。

### 环境与限制

支持Linux、Windows和macOS；当前代码要求Qt6.9+，不再支持Qt5.15和Windows7。不同格式支持编辑或阅读的范围不同，内置PDF查看不等于完整PDF编辑。第三方图标保留独立许可。

### 开始使用

从正式发行下载平台包，建立笔记目录后试用Markdown与目标格式。 参阅[官方 README](https://github.com/vnotex/vnote/blob/master/README.md)。

## English

Manages local notes and edits Markdown, Typst, text and mind maps.

### Uses and features

- Organize technical notes and documents

Provides Markdown preview, live Typst PDF preview, text/code editing, native mind maps and PDF reading.

### Requirements and limits

Supports Linux, Windows and macOS; current code requires Qt 6.9+, with Qt 5.15 and Windows 7 unsupported. Editing and reading support differ by format; a PDF viewer is not a full PDF editor. Third-party icons retain separate licenses.

### Getting started

Download a stable platform release, create a notebook directory and try Markdown and your target format. See the [official README](https://github.com/vnotex/vnote/blob/master/README.md).

### Review and provenance
