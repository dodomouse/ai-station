## 中文

以Markdown笔记本组织笔记、待办和附件，支持搜索与同步。

### 用途与功能

- 管理个人知识与待办
- 跨设备访问笔记

提供标签、全文搜索、桌面与移动客户端，以及网页剪藏和扩展接口。

### 环境与限制

本词条收录默认AGPL许可下的客户端代码；部分内容另有条款，包括服务器目录、图标与商标。同步服务、加密和扩展需按所选路径配置。外部AI或云服务可能收费并接收笔记内容。

### 开始使用

Organizes Markdown notes, tasks and attachments into notebooks with search and synchronization.

### Uses and features

- Manage personal knowledge and tasks
- Access notes across devices

Provides tags, full-text search, desktop/mobile clients, Web clipping and extension interfaces.

### Requirements and limits

This entry covers client code under the default AGPL license; server directories, icons and trademarks have separate terms. Configure synchronization, encryption and extensions for the chosen path. External AI or cloud services may charge fees and receive note content.

Install an official client release, create local notes, then choose synchronization and verify backups. See the [official README](https://github.com/laurent22/joplin/blob/dev/README.md).
