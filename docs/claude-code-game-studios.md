## 中文

### 用途与功能

为 Claude Code 提供游戏开发模板和技能。可从玩法描述生成简要设计、浏览器原型，并逐步修改和扩展。

提供角色分工、引擎配置、任务拆解和验证流程。默认可从浏览器游戏开始，另有 Godot、Unity 和 Unreal 配置。

### 环境与限制

需要 Claude Code、Git、Python 3 和 Bash。浏览器验证需要 Chrome、Edge 或 Chromium；扩展 Web 工程通常需要 Node.js。模板的自动检查不代替人工试玩，README 明确说明引擎路线的效果证据有限。

### 入门与收录判断

从[官方 README](https://github.com/Donchitos/Claude-Code-Game-Studios/blob/main/README.md)查阅安装和配置步骤。把需求、可玩原型和检查结果连接起来，并明确说明验证范围，适合原型开发。

本轮为文档复核，未安装、运行或测试上游软件。正式 v1.3.0 重构 /prototype 主流程，加入简报、浏览器检查和后续扩展。详见[维护记录](https://github.com/Donchitos/Claude-Code-Game-Studios/releases/tag/v1.3.0)。

## English

### Purpose and features

A Claude Code template and skill collection for turning a game idea into a brief, browser prototype and incremental implementation.

Provides role definitions, engine configuration, task decomposition and checks, with browser-first workflows and optional Godot, Unity or Unreal routes.

### Requirements and limits

Requires Claude Code, Git, Python 3 and Bash. Browser checks need Chrome, Edge or Chromium; growing a web project generally needs Node.js. Automated checks do not replace playtesting, and the README identifies limited validation of engine routes.

### Getting started and review

Use the [official README](https://github.com/Donchitos/Claude-Code-Game-Studios/blob/main/README.md) for installation and configuration. This is a documentation review; the software was not installed or tested. Stable v1.3.0 rebuilds /prototype around a brief, browser checks and incremental growth. See the [release](https://github.com/Donchitos/Claude-Code-Game-Studios/releases/tag/v1.3.0).
