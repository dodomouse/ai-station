**环境与限制：** 面向 macOS、Windows、Linux，需 Rust 工具链与平台图形依赖；组件和后端支持情况见文档。代码采用 Apache-2.0，部分文档另提供 CC-BY-4.0 授权。

## English

A Rust GPUI desktop component library with tables, editors, layouts, accessibility support and an optional JavaScript host.

**Requirements and limitations:** Targets macOS, Windows and Linux, requiring Rust and platform graphics dependencies. Consult the docs for component and backend support. Code uses Apache-2.0; some documentation additionally offers CC-BY-4.0.

**Getting started:** Follow the [official documentation](https://raw.githubusercontent.com/longbridge/gpui-kit/main/README.md) for setup, then check [releases](https://github.com/longbridge/gpui-kit/releases). This review examined documentation, license text and maintenance evidence; the software was not installed or run.
