## 中文

可在浏览器中旋转、拆分、搜索和选择人体结构的三维解剖图谱。

### 主要功能

- 按解剖系统切换显示，并查看部件说明。
- 提供单项隔离、展开排列和移动端布局。

### 环境与限制

- 本机运行需要 Node.js 22.13+，无需模型账号。
- 代码为 MIT，BodyParts3D 数据为 CC BY 4.0，成人男性参考模型不涵盖全部人体差异。

### 开始使用

从[官方说明](https://github.com/ashemag/human-atlas/blob/main/README.md)选择对应平台或集成方式，核对依赖与权限后按入门步骤操作。[发行记录](https://github.com/ashemag/human-atlas/releases)可用于确认版本。

## English

A browser-based 3D anatomy atlas for rotating, separating, searching and selecting structures.

### Features

- Toggles anatomical systems and displays structure details.
- Supports isolation, exploded layouts and mobile controls.

### Requirements and limits

- Local setup needs Node.js 22.13+ and no model account.
- Code is MIT and BodyParts3D data is CC BY 4.0
- the adult male reference does not cover all human variation.

### Getting started

Choose the platform or integration in the [official documentation](https://github.com/ashemag/human-atlas/blob/main/README.md), review its dependencies and permissions, and follow its quickstart. Check [release records](https://github.com/ashemag/human-atlas/releases) for versions.
