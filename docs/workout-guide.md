## English

A visual exercise reference and npm dataset covering 302 movements, with illustrated frames, typed lookups, search and a static gallery for exercise-content interfaces.

**Requirements and limitations:** JavaScript/TypeScript applications can import ESM or CommonJS data. Code uses MIT; illustrations use CC-BY-SA-4.0 and require attribution and share-alike compliance.
